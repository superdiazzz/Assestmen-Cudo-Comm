# Mobile Offline Queue Assessment

## Requirements

- Node.js 22 or newer
- npm

## Installation

```bash
npm install
```

## Available commands

```bash
npm test
npm run typecheck
```

## Repository structure

```text
src/    TypeScript domain, queue, synchronization, API, and infrastructure code
tests/  Candidate-visible Jest tests
```

## How to run tests

```bash
npm test
```

## Expected baseline test state

The starter repository intentionally begins with two passing test suites and one failing test suite. The failing scenario represents a production reliability issue to investigate during the assessment.
